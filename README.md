# ⚡ EV Service — Electric Vehicle Servicing Platform

A full stack web application where electric vehicle owners can browse 
and book servicing appointments online.

[View Live](https://ev-service-lemon.vercel.app)

## 📋 About The Project
EV Service is a platform designed to simplify the process of booking 
electric vehicle servicing. Users can create an account, log in, and 
schedule service appointments — all from one clean interface.

## ✨ Current Features
- User registration and login (Authentication)
- Service booking system
- Responsive design across all devices
- Secure password handling

## 🚧 Upcoming Features
- Online payment integration
- Booking history & status tracking
- Admin dashboard for managing appointments
- Email/SMS booking confirmation
- Service center locator with map
